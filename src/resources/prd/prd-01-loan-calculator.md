## 背景与问题

个人用户在申请或调整房贷、车贷、消费贷时，需要在手机上**快速试算月供、总利息和还款结构**，并可能希望**保存多组方案**、为月供准备**缓冲储蓄**，同时**不愿将财务数据上传云端**。

现有商店中的 EMI 计算器、储蓄目标类 App 提供了功能结构参考，但本项目目标是产出一套**可运行、接近正式产品**的参考原型，供后续贷款类产品设计复用，而非复制某一竞品 UI。

**依据：** 用户确认的需求范围（src-005）、主规格 HTML（src-001）、已实现原型（src-002）。

## 目标与成功标准

| 目标 | 成功标准 |
| --- | --- |
| 可信试算 | 等额本息/等额本金结果与常见银行/EMI 计算器一致（允许分位四舍五入差异） |
| 闭环可用 | 用户可在无网络下完成：输入 → 结果 → 摊还 → 保存 → 历史复看 |
| 轻量储蓄 | 可创建目标、记录存入/取出，进度与目标额一致；可从贷款结果一键带入建议目标额 |
| 数据自主 | 数据仅存本机；支持 JSON 导出；用户可清空业务数据并保留偏好 |
| 体验达标 | 手机端单手操作、大数字可读、主流程 3 步内可达结果页；视觉符合 Revolut Mobile 浅色气质 |

## 用户、角色与场景

**主要用户：** 有贷款规划需求的个人用户（非企业信贷员）。

**典型场景：**

1. **首次试算：** 打开 App → 确认/修改预填参数 → 查看实时预览 → 计算 → 查看环形图与汇总 → 可选保存。
2. **看清还款结构：** 在结果页进入摊还明细，按月（或按年汇总）查看本金、利息、剩余本金。
3. **复看方案：** 在记账 Tab 按标签筛选或搜索 → 打开贷款方案详情 → 复看结果。
4. **记一笔：** 在记账 Tab 记录与贷款相关的收入/支出，打标签便于归类。
5. **月供缓冲：** 在结果页选择为月供储蓄 → 储蓄 Tab 新建目标（金额预填，可改）→ 后续存入/取出。
6. **偏好与备份：** 在「我的」修改昵称、货币与小数位 → 导出 JSON 备份 → 必要时分项清空数据。

## 范围

### 本次包含

- 底部四 Tab：**计算 / 储蓄 / 记账 / 我的**
- 还款方式：**等额本息**、**等额本金**
- 输入：本金、年利率（%）、期限（年 + 月，内部折算月数）；贷款类型标签（房贷/车贷/消费贷等，**仅分类**，不影响公式）
- 输出：月供（或等额本金首月）、总利息、还款总额、本金/利息占比可视化、摊还明细
- **记账**：保存的贷款方案（标签、收藏）+ 手动手收支「记一笔」；标签筛选与搜索；方案/收支分区展示
- 储蓄：目标新建/编辑/删除、存入与取出、进度环、可选关联计算记录；列表「智能提示」：达标时间预测（按存入节奏）、3～6 个月月供缓冲建议
- 个人中心：本地昵称与头像（emoji）、偏好设置、数据管理（导出、分项清空）、关于与隐私（强调离线）
- **12 种显示货币**（ISO 4217），仅在偏好设置切换；`Intl` 格式化；**无汇率换算**
- 首次使用可注入示例数据（可在数据管理中清空）

### 不在本次范围

- 登录、云端、多设备同步
- 两笔贷款**并排对比**、提前还款试算、反推利率或期限
- 完整家庭预算、记账、银行账户对接
- 真实合规披露、征信、放款流程
- 系统级还款提醒 Push（开关可占位）
- JSON **导入**恢复（v1 仅导出，除非后续单独立项）

## 用户故事

1. 作为**准借款人**，我希望输入金额、利率和期限后立即看到月供与总利息，从而判断是否在可承受范围内。
2. 作为**对比方案的用户**，我希望保存多次试算并在记账中按标签筛选，从而复看而不重新输入。
3. 作为**注重细节的用户**，我希望查看逐月摊还表，从而理解前期利息占比。
4. 作为**谨慎理财的用户**，我希望为某笔贷款的月供设储蓄目标并记录存入，从而建立缓冲金。
5. 作为**隐私敏感用户**，我希望数据只存在手机浏览器且可导出，从而自主备份或迁移（导出侧 v1）。
6. 作为**跨境或外币习惯用户**，我希望在设置中选择显示货币符号与格式，从而按习惯阅读金额（数值不随汇率变化）。

## 能力与信息架构

```text
[计算 Tab]
  首页（输入 + 实时预览 + 计算 CTA）
    → 结果（汇总 + 环形图 + 保存/收藏 + 摊还/储蓄入口）
      → 摊还明细
[储蓄 Tab]
  列表 → 详情（流水、存入/取出、编辑）
[记账 Tab]
  首页（统计 / 标签筛选 / 贷款试算区 / 收支明细区）
    → 记一笔
    → 方案详情（改标签、复看结果）
    → 收支详情（改标签、备注）
[我的 Tab]
  首页 → 偏好设置 | 数据管理 | 关于与隐私
```

Hash 路由示例：`#page=calc`、`calc-result`、`amortization`、`savings`、`savings-detail`、`ledger`、`ledger-new`、`ledger-detail`、`ledger-manual-detail`、`profile` 及子页。旧 `history*` 路由可重定向到 `ledger*`。

## 业务规则

### 计算

| 条件 | 规则 |
| --- | --- |
| 本金 | 必须 &gt; 0 |
| 年利率 | ≥ 0，按年化百分比输入 |
| 期限 | 年 + 月折算总月数 &gt; 0 |
| 等额本息 | 月供固定（最后一期可因舍入微调） |
| 等额本金 | 每月本金固定，月供递减；结果页突出**首月**还款 |
| 贷款类型 | 仅影响展示与历史标签，不参与公式 |

### 保存与记账

- 保存试算结果写入「贷款试算」区；默认 tags 含贷款类型（房贷/车贷等），详情页可增删标签。
- 收藏/删除方案；搜索匹配标题、还款方式或标签。
- 「记一笔」写入收支明细；支出/收入不可为 0；至少一个标签。
- 首页标签 chips：点选筛选，再点取消；「全部」显示所有条目。
- 删除需确认；删除后不可恢复（除非有导出备份）。

### 储蓄

- 目标额必须 &gt; 0；当前额不可为负（取出时校验余额）。
- 从结果页「为月供储蓄」：**默认目标金额 = 3 × 当期月供**（用户可修改）；跳转储蓄新建流程。
- **达标预测：** 根据该目标历史「存入」流水与已存时长，估算平均月存入 pace；展示「还差 X；约 N 个月后有望达标」。无存入时提示开始存入后再预测。
- **月供缓冲建议：** 文案固定引用 **3～6 个月月供**；若 `linkedCalcId` 有效，用关联方案月供换算「当前约 X 个月月供」并判断是否在 3～6 区间内。

### 货币

- 支持：CNY、USD、EUR、GBP、INR、JPY、HKD、SGD、AUD、CAD、KRW、THB。
- 切换货币**不换算**已存数值，仅改变展示格式与符号。
- **计算首页不提供货币网格**；仅在「我的 → 偏好设置」选择并保存。

### 数据管理

- **导出：** 打包业务 JSON 供用户下载。
- **清空：** 分项清空计算与储蓄等业务数据；**保留**偏好与个人资料（与主规格一致）。
- 清除浏览器站点数据将导致全部丢失——关于页需说明。

## 状态、异常与边界

| 场景 | 表现 |
| --- | --- |
| 校验失败 | 非法字段高亮（错误色），不跳转结果页 |
| 空历史 / 空储蓄 | 空状态文案 + 引导 CTA（去计算 / 新建目标） |
| 无 pending 结果进入结果页 | 重定向或空态提示 |
| 历史 id 不存在 | 提示记录不存在并返回列表 |
| 导出失败 | Toast 或内联错误（如浏览器阻止下载） |
| 清空确认 | 二次确认；成功后 Toast |
| 离线 | 无网络请求；功能不受影响 |

## 字段、内容与交互要求

### 计算首页

- Banner：强调离线、本地数据、已存方案数（若有）。
- 还款模式切换；贷款类型图标格；本金、利率、年+月期限；快捷期限 chips（可选）。
- **实时预览**月供（或首月）与总利息。
- 主按钮「计算」使用紫蓝渐变 CTA。

### 结果页

- Hero 展示核心还款数字；总利息、还款总额；本金 vs 利息环形图（入场动画约 700ms）。
- 操作：保存、收藏、摊还明细、为月供设储蓄。

### 摊还明细

- 列表展示期次、月供、本金、利息、剩余本金；支持按月/按年汇总切换（若实现）。

### 储蓄

- 列表卡片含进度环；其下「智能提示」卡片两行（达标预测、3～6 个月月供建议）；新建/编辑；详情页流水与存入/取出。

### 记账

- 顶栏统计：贷款方案数、收支笔数、本月收支笔数。
- 主 CTA「记一笔」；次 CTA「去试算并保存方案」。
- 标签筛选条 + 搜索框。
- 分区：贷款试算（收藏星标）、收支明细（金额正负色）。
- 详情页可编辑标签；方案详情可打开完整计算结果。

### 我的

- 统计已存方案与储蓄目标数；菜单进入偏好、数据管理、关于与隐私。
- 偏好：昵称、头像 emoji、小数位、**货币网格**、保存。
- 数据管理：导出 JSON、清空业务数据（确认）。
- 关于：版本、离线说明、隐私（不上传服务器）。

### 设计表达

- 基底：**Revolut Mobile**（src-004）。
- 原型确认：**浅色画布** `#F4F4F8`、白卡片、渐变 CTA `#5B6BFF → #9C6BFF`、tabular 数字、环形图。
- 字体：Inter 作为 Aeonik 替代。
- 不实现金属卡 3D 等 Revolut 签名动效。
