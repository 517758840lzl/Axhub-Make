## 背景与问题

个人用户在申请或调整房贷、车贷、消费贷时，需要在手机上快速试算月供、总利息和还款结构，保存多组方案并排对比，并为月供准备缓冲储蓄，同时不愿把财务数据上传云端。

本产品是一套可运行、接近正式产品的贷款计算器：Web 原型与 Flutter 真机都按同一套规则交付。主线是试算与对比，不承担日常记账。应用显示名为 LoanCalcMate，桌面图标、启动页和计算首页标题都用这个名字。

**依据：** 2026-10-15 用户确认的范围（src-005、src-007）、主规格 HTML（src-001）、已实现原型（src-002）、已对齐的 Flutter 真机（src-008）。

## 目标与成功标准

| 目标 | 成功标准 |
| --- | --- |
| 可信试算 | 等额本息 / 等额本金结果与常见银行或 EMI 计算器一致，允许分位四舍五入差异 |
| 闭环可用 | 无网络下可完成：选类型 → 输入 → 结果 → 摊还 → 保存 → 在「我的」复看 |

| 数据自主 | 数据仅存本机；可导出 JSON；可清空业务数据并保留偏好 |
| 两端一致 | Web 原型与 Flutter 真机在本文规则上表现相同 |
| 体验达标 | 手机端单手操作、大数字可读、主流程 3 步内到达结果页；视觉为 Revolut Mobile 浅色 |

## 用户、角色与场景

**主要用户：** 有贷款规划需求的个人用户（非企业信贷员）。

**典型场景：**

1. **首次试算：** 打开应用 → 选房贷、车贷、消费贷或组合贷 → 改预填参数并看实时摘要 → 计算 → 看环形图、解读和汇总 → 可选保存。
2. **车贷：** 填车价和首付，贷款额随动，结果里能看到车价、首付和贷款额。
3. **看清还款结构：** 从结果页进入摊还明细，按月查看本金、利息和剩余本金。
4. **对比方案：** 从结果或已保存方案加入对比；凑满 2 个后看摘要和并排表，最多 3 个。
5. **复看方案：** 在「我的 → 已保存方案」打开、收藏、删除，或从「对比中」进入当前对比。
6. **月供缓冲：** 在结果页为月供设储蓄 → 储蓄页新建目标（金额预填，可改）→ 后续存入 / 取出。
7. **偏好与备份：** 在「我的」点头像改昵称和头像；在偏好设置改语言、货币和小数位 → 导出 JSON → 必要时清空业务数据。

## 范围

### 本次包含

- 底部三 Tab：**计算 / 储蓄 / 我的**
- 贷款类型：房贷、车贷、消费贷、**组合贷**（两笔通用贷款合并试算，不是公积金专项）
- 还款方式：**等额本息**、**等额本金**
- 房贷 / 消费贷输入：本金、年利率（%）、期限（年 + 月）
- 车贷输入：车价、首付（比例快捷项 + 金额可改）、贷款额、年利率、期限、还款方式
- 组合贷输入：两笔各自的本金、年利率、期限
- 输出：月供（等额本金看首月到末月）、总利息、还款总额、本金 / 利息占比、最多 3 条结果解读、摊还明细
- **多方案对比**：最多 3 个、至少 2 个才出对比表；可从结果或已保存方案加入，也可在对比页移除
- 已保存方案：放在「我的」，含收藏、对比、删除和「对比中」入口
- 储蓄：目标新建 / 编辑 / 删除、存入与取出、进度环；从结果预填约 3 倍月供
- 个人中心：本地昵称与头像、偏好（语言、货币、小数位）、数据管理、关于我们、隐私协议
- 界面语言：**简体中文 / English / Español**，在偏好设置切换
- 默认按 CNY 展示。偏好设置可切换其余显示货币，列表里不放 CNY。只改展示格式，无汇率换算
- 首次可注入示例数据，并在数据管理中清空
- Web 原型与 Flutter 真机都交付上述能力

### 不在本次范围

- 记账 Tab、手收支、「记一笔」、标签账本
- 法式 / 德式 / 美式还款算法、可负担评估、PDF / Excel 导出
- 登录、云端、多设备同步、KYC、真实放款
- 提前还款、部分还款、反推利率或期限
- 系统级还款提醒
- JSON 导入恢复（当前仅导出）
- 深色主题完整切换（当前以浅色为准）

## 用户故事

1. 作为**准借款人**，我希望输入金额、利率和期限后立即看到月供与总利息，从而判断是否承受得起。
2. 作为**买车的用户**，我希望用车价和首付算出贷款额，从而不用自己先减一遍。
3. 作为**要比较方案的用户**，我希望把 2～3 个方案放在一起，并直接看到谁的总利息更少、谁的月供更低。
4. 作为**注重细节的用户**，我希望查看逐月摊还，从而理解前期利息占比。
5. 作为**谨慎理财的用户**，我希望为月供设储蓄目标并记录存入，从而准备缓冲金。
6. 作为**隐私敏感用户**，我希望数据只留在这台设备上，并能导出备份。
7. 作为**跨语言用户**，我希望在设置里切换中文、英文或西班牙文，以及货币符号，金额数值不随汇率变化。

## 能力与信息架构

```text
[计算 Tab]
  首页（类型 + 输入 + 实时摘要 + 计算）
    → 结果（汇总 + 环形图 + 解读 + 摊还 / 加入对比 / 保存 / 设储蓄）
      → 摊还明细
      → 多方案对比（2～3）
[储蓄 Tab]
  列表 → 详情（流水、存入 / 取出、删除）
[我的 Tab]
  首页
    → 已保存方案 → 结果 / 对比
    → 点头像进入编辑资料（昵称、头像、性别）
    → 偏好设置（语言、小数位、货币）| 数据管理 | 关于我们 | 隐私协议
```

Web 原型用 hash 路由，例如 `#page=calc`、`calc-result`、`amortization`、`compare`、`savings`、`savings-detail`、`profile` 及已保存方案子页。Flutter 使用应用内同等页面，不暴露浏览器地址。

旧的记账 / 历史路由不在界面中提供入口。

## 数据模型

数据只存在本机。Web 使用 localStorage，Flutter 使用本机偏好存储；键前缀均为 `loan-calc:`。无加密要求。导出为 UTF-8 JSON。

### 用户资料（Profile）

| 字段 | 说明 |
| --- | --- |
| nickname | 显示昵称，默认「借款人」 |
| avatar | emoji 或预设标识 |
| gender | `male` / `female` / `private`，缺省按保密 |
| createdAt | 本地创建时间 |

### 偏好（Settings）

| 字段 | 说明 |
| --- | --- |
| locale | `zh-CN` / `en` / `es`，默认简体中文 |
| currencyCode | ISO 4217，默认 CNY |
| decimals | 0–4，切换货币时可带入该币种默认小数位 |
| theme | 预留 dark / light / system；当前产品以浅色为准 |

### 计算记录（Calculation）

| 字段 | 说明 |
| --- | --- |
| id | 唯一标识 |
| mode | 等额本息 / 等额本金 |
| category | 房贷 / 车贷 / 消费贷 / 组合贷 |
| 输入 | 本金或车价与首付、年利率、期限（月）；组合贷为两笔输入 |
| 输出摘要 | 月供或首末月、总利息、总额等 |
| schedule | 摊还明细 |
| favorite | 是否收藏 |
| label | 可选备注；为空时列表标题用还款方式，例如「等额本息」 |
| createdAt | 保存时间 |

相同输入再次保存时不新增一条，沿用已有记录。

### 对比槽

当前对比中的计算记录 id，最多 3 个。只引用已保存方案，不单独保存一份「未落库」的对比项。

### 储蓄目标（SavingsGoal）

| 字段 | 说明 |
| --- | --- |
| id | 唯一标识 |
| name | 目标名称 |
| target / current | 目标额与当前额 |
| deadline | 可选截止日期 |
| linkedCalcId | 可选关联计算 id |
| transactions | 存入 / 取出流水 |

### 元数据（Meta）

| 字段 | 说明 |
| --- | --- |
| schemaVersion | 结构版本 |
| seeded | 是否已注入示例数据 |

示例数据用于第一次打开时的验收：至少包含可复看的房贷方案，以及一个储蓄目标。已有本地数据不被覆盖。

## 业务规则

### 计算

| 条件 | 规则 |
| --- | --- |
| 本金 | 必须大于 0 |
| 年利率 | 大于等于 0，按年化百分比输入 |
| 期限 | 年 + 月折算的总月数大于 0 |
| 等额本息 | 月供固定，最后一期可因舍入微调 |
| 等额本金 | 每月本金固定，月供递减；结果页突出首月到末月 |
| 房贷 / 消费贷 | 本金直接输入 |
| 车贷 | 贷款额 = 车价 − 首付；用户可以改贷款额。首付可用比例快捷项，也可以改金额 |
| 组合贷 | 两笔分别计算后合并展示合计月供、总利息和总成本 |
| 贷款类型 | 决定表单和结果里的专用信息；不改变等额本息 / 等额本金公式 |

### 结果解读

- 普通方案最多 3 条：还款方式与年限及利息占比、月供与总利息、本金与年利率。
- 车贷在上述内容前增加车价、首付、贷款额说明，仍最多展示 3 条。
- 组合贷解读合计月供、总利息、总成本，并带上两笔本金和利率。
- 金额按整数读出，便于扫读。

### 保存

- 结果页在当前方案尚未保存时显示「保存方案」。
- 保存成功后提示已保存到「我的」，并隐藏该按钮。再次打开同一结果也不再显示。
- 未填备注时，列表标题为还款方式。
- 相同方案已存在时不新增，并提示未重复添加。

### 对比

- 对比槽最多 3 个；少于 2 个时不展示对比表，并提示再选一个。
- 从结果页「加入对比」时，先按上面的保存规则落库（已存在则静默沿用），再把该方案放入对比槽。
- 放入后若仍只有 1 个，提示再选一个即可对比；放进第 2 个时直接进入对比页。
- 已保存列表始终保留对比操作。未在槽内时按钮是「对比」；已在槽内时按钮是「退出对比」，点它只把这一条移出槽位，人留在列表。「对比中」点它进入对比页。
- 对比未满 3 个时，页底列出尚未加入的已保存方案，点按后加入当前对比，不强制离开后再进。
- 摘要点名总利息最少的方案和总利息最多的方案，写明利息差额；同时点名月供最低的方案和金额。方案名称带上类型、利率和期限，避免只写「房贷」。
- 表头保持单行，只显示类型和利率。期限在表格里单独一行，不拼进表头。

### 储蓄

- 目标额必须大于 0；当前额不可为负。取出金额大于当前余额时提示「余额不足」，不记流水、不改当前额。
- 从结果页「为月供设储蓄目标」：默认目标金额约为 3 倍当期月供，用户可改。

### 货币与语言

- 货币：CNY、USD、EUR、GBP、INR、JPY、HKD、SGD、AUD、CAD、KRW、THB。
- 切换货币不换算已存数值，只改变符号和格式。
- 计算首页不提供货币选择；只在「我的 → 偏好设置」修改。
- 语言切换后，界面文案随之改变；已保存的用户备注保持原样。

### 数据管理

- **导出：** 打包业务 JSON。Web 为浏览器下载，真机为系统分享。
- **清空：** 删除计算与储蓄等业务数据，保留昵称、语言、货币等偏好。操作前需确认。
- 清除站点数据或卸载应用会导致全部丢失。隐私协议在页内加载远程页面，正文不写在应用里。当前地址为 https://www.bluebirdfintech.com/profile/privacy-consent/provision.html。

### 删除

- 删除已保存方案前使用应用内确认，确认后不可恢复（除非已有导出备份）。

## 字段、内容与交互要求

### 计算首页

- 类型入口：房贷、车贷、消费贷、组合贷。
- 还款方式；本金、利率、期限；快捷期限。车贷改为车价、首付、贷款额。组合贷为两笔参数。
- 实时摘要：月供（或首月）与总利息。
- 「本息占比」「摊还明细」「方案对比」三个入口放在「计算」按钮上方。
- 主按钮使用紫蓝渐变。

### 结果页

- Hero 展示核心还款数字。组合贷展示两笔合计月供；等额本金展示首月到末月。
- 总利息、还款总额。单笔贷款的环形图是本金与利息，圆心为利息占比。组合贷的环形图按两笔月供切开，圆心是第一笔占合计月供的百分比；下面列出每笔的本金、利率、月供和总利息。
- 车贷展示车价、首付、贷款额。
- 「结果解读」最多 3 条。
- 操作：摊还明细、加入对比、保存方案（已保存则不显示）、为月供设储蓄目标。

### 摊还明细

- 列：期数、还款、本金、利息、余额。五列居中，行高与列间距按真机。
- 筛选和表格放在白色卡片里，整页滚动，表格拉满卡片宽度。
- 绑定当前结果，可返回结果页。

### 对比页

- 顶部摘要、明细表、柱状图（月供 / 总利息 / 总成本）。
- 表格含还款方式、首末月供、利息占比、日均利息，以及类型或首付等能区分方案的字段。
- 可移除；未满 3 个时底部可继续加入已保存方案。

### 储蓄

- 列表卡片含进度环；新建；详情页流水、存入 / 取出，以及删除。删除需确认，确认后回到列表。

### 我的 · 已保存方案

- 卡片顺序：标题、可点的「对比中」、实心收藏星、本金 / 利率 / 期限、月供，以及「收藏 / 取消收藏」「对比 / 退出对比」「删除」。
- 点卡片主体打开该方案结果。点「对比中」进入对比页。未在槽内时「对比」把该方案加入对比槽；已在槽内时「退出对比」只移出这一条。
- 未收藏的方案不显示收藏星；对比按钮一直保留，文案随是否已在槽内切换。

### 我的 · 其他

- 点头像进入编辑资料，改昵称、头像和性别（男 / 女 / 保密）。保密用默认头像，男和女各有不同的默认头像；自己改过的头像不随性别替换。偏好设置只改语言、小数位和货币。小数位跟货币放在一起，换货币时小数位随该货币的默认位数更新。保存后全站生效。
- 数据管理：导出 JSON、清空计算与储蓄（确认，保留偏好）。
- 关于我们：服务于准备借款的用户，说明测算与方案比较、四类贷款、两种还款方式、摊还、对比、储蓄，以及语言和货币展示。
- 隐私协议：页内打开远程页面，正文不写在应用里。当前地址为 https://www.bluebirdfintech.com/profile/privacy-consent/provision.html。

### 设计表达

- 基底：Revolut Mobile（src-004）。
- 浅色画布 `#F4F4F8`、白卡片、渐变 CTA `#5B6BFF → #9C6BFF`、等宽数字、环形图。
- 收藏使用实心五角星。
- 提示为浅色底、深色字，靠页面中下部，不挡操作。
- 不实现金属卡 3D 等 Revolut 签名动效。

| 可用性 | 关键金额大字号；底部 Tab 可识别 |

## 开放问题

1. **JSON 导入：** 当前假设只导出，不在本版恢复数据。
2. **保存时的货币：** 当前假设不把币种固化进每条方案，换货币只改显示格式。
3. **深色主题：** 当前假设固定浅色，主题字段仅预留。
4. **尚未指定以哪一端为准的呈现：** 清空全部数据时的确认样式。摊还表已定为五列居中、白卡片、整页铺满内容宽度。组合贷环形图已按原型：环切两笔月供，圆心为第一笔占比。
