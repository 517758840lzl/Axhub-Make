# 贷款计算器

## 产品概览

- **一句话定位：** 手机端优先的离线贷款试算与轻量储蓄目标工具，帮助个人用户快速规划房贷、车贷或消费贷并保存方案。
- **产品背景：** 作为 Ax Make 项目内的参考产品，Web 原型与 Flutter 真机沉淀同一套贷款闭环（计算 → 结果/摊还 → 对比 → 保存 → 我的），并可关联月供缓冲类储蓄目标。
- **产品目标：** 在无账号、无服务端前提下，提供可信的等额本息/等额本金计算、摊还明细、多方案对比、本地方案与偏好管理，界面接近生产级金融工具。

## 用户与场景

| 用户/角色 | 使用场景 | 核心任务 |
| --- | --- | --- |
| 个人借款人 | 购房/购车/消费贷前在手机上演算 | 输入本金、利率、期限，查看月供与总利息 |
| 已有方案用户 | 对比或复看已保存试算 | 收藏、加入对比、打开方案 |
| 注重隐私用户 | 不愿上传财务数据 | 离线使用、本地存储 |
| 储蓄规划用户 | 为月供准备缓冲金 | 创建储蓄目标、记录存入/取出 |

## 产品范围

### 包含

- 等额本息、等额本金计算与按月摊还明细
- 三 Tab：计算、储蓄、我的
- 房贷、车贷、消费贷、组合贷；车贷使用车价与首付
- 多方案对比（2～3 个）；已保存方案放在「我的」
- 轻量储蓄目标与进度；结果页可预填约 3 倍月供
- 个人中心：昵称/头像、英/西语言、货币与小数位、清空业务数据、关于我们、隐私协议
- Web 原型与 Flutter 真机遵守同一产品规则；数据只在本机

### 不包含

- 账号体系、云端同步、真实放款/KYC
- 记账、手收支、「记一笔」
- 提前还款、反推利率/期限、PDF/Excel、JSON 导入与导出
- 系统 Push 通知
- 汇率换算（切换货币仅影响显示格式）
