贷款计算器

手机端优先的离线贷款计算与轻量储蓄目标工具：等额本息 / 等额本金、摊还明细、历史与个人中心闭环；数据仅存本地，不对接服务器。视觉以 Revolut Mobile 设计基底（深色驾驶舱 + 紫蓝渐变强调 + 环形分析）为准。

当前方案

  • 原型意图：作为后续贷款类 App 的参考原型，演示完整用户闭环与常见计算能力。
  • 目标用户：有房贷、车贷或消费贷规划需求的个人用户；希望在手机上快速试算并保存方案。
  • 核心体验：底部四 Tab（计算 / 储蓄 / 记账 / 我的）；大数字结果、渐变主操作、储蓄进度环；记账含标签筛选与手收支；全程离线可用。
  • 参考产品（结构参考，非 UI 抄袭）：Google Play EMI Calculator（Lnkup）、Savings Goal Tracker（Cash247）、Simple Budget Planner（CashMe）。

事实与输入

用户确认事实

  • 范围：贷款为主 + 轻量储蓄目标（可为月供/某笔贷款设缓冲金），不做完整预算记账。
  • 端形态：手机端优先（约 390×844 视口，底部 Tab，单手操作）。
  • 计算模式：等额本息、等额本金；结果页含摊还明细（按月）。
  • 双方案对比：本轮不做（二期）。
  • 个人中心：昵称/头像（本地）、记账与收藏、货币/小数/主题偏好、JSON 导出与清空、关于与隐私（强调离线）。
  • 数据：仅 localStorage，无登录、无网络 API。
  • 设计基底：Revolut Mobile（src/themes/revolut-mobile/DESIGN.md）。

参考资料

  • Play Store 三款金融工具（EMI / 储蓄 / 预算）— 功能范围与离线隐私表述参考。
  • 主题色板对照：src/resources/loan-calc-theme-colors.html。
  • Make 主题预览：?projectId=amake-demo&theme=revolut-mobile。

当前假设

  • 默认货币 CNY（¥）；支持 12 种常用货币，仅在「我的 → 偏好设置」切换；全站金额按 Intl 格式化（仅改显示符号与格式，不做汇率换算）。
  • 示例种子数据：首次安装可预置 1～2 条示例计算与 1 个储蓄目标，便于验收（可在设置中清空）。
  • 期限输入支持「年 + 月」或统一折算为月数内部计算。

原型范围

本次呈现

  • 多页面单原型（hash 路由）：计算首页、结果/摊还、储蓄列表与详情、历史列表与详情、个人中心及子页（偏好、数据管理、关于）。
  • 等额本息 / 等额本金公式与摊还表（前端计算，精度与常见银行计算器一致即可）。
  • 保存计算到记账（带标签）、收藏、标签筛选与搜索；手动的「记一笔」收支；从结果页「为这笔月供设储蓄目标」跳转并预填金额。
  • 储蓄：目标 CRUD、存入/取出、进度环与简单统计。
  • Revolut 浅色 UI：画布 #F4F4F8、白卡片、紫蓝渐变 CTA、tabular 金额、环形图展示本金/利息或储蓄进度。

本次不呈现

  • 服务器同步、账号体系、真实 KYC/放款流程。
  • 双贷款方案对比、提前还款试算、反推利率/期限（二期）。
  • 完整预算记账、多账户银行流水。
  • Push 通知（可预留「提醒」开关 UI，不实现系统通知）。

交互与状态方案

对象/场景前置状态用户操作原型表现后续状态
提交计算 必填项完整且数值合法。 点击「计算」。 跳转结果页，播放环形图 draw 动画（约 700ms）。 可保存或查看摊还。
校验失败 本金≤0、利率非法或期限为 0。 点击「计算」。 字段高亮 #FF5A6A，不跳转。 修正输入。
保存计算 结果页已展示。 保存 / 收藏。 写入 localStorage；Toast「已保存」。 记账列表可见。
设储蓄目标 结果页有有效月供。 选择「为月供储蓄」。 跳转储蓄新建，目标金额预填为 3× 月供（可改）。 储蓄 Tab 出现新目标。
空状态 无记账 / 无储蓄目标。 进入对应 Tab。 Revolut 式空状态文案 + 渐变 CTA 引导。 —
导出 / 清空 我的 → 数据管理。 导出 JSON 或确认清空。 下载文件 / 二次确认后 wipe 本地 key。 列表清空，偏好可保留（待确认实现为全部清空或分项）。

流程与本地数据

所有业务数据写入浏览器 localStorage，键名前缀 loan-calc:；无加密要求，导出为 UTF-8 JSON 文件。

localStorage 结构（草案）

键内容
loan-calc:profile昵称、头像（emoji 或 preset id）、创建时间。
loan-calc:settings货币符号、小数位、主题（dark/light/system，默认 dark）。
loan-calc:calculations贷款方案数组：id、模式、输入、输出、摊还、收藏、tags[]、createdAt。
loan-calc:ledger-entries手收支数组：id、title、amount、direction、tags[]、note、createdAt。
loan-calc:savings-goals目标数组：id、名称、target、current、deadline、linkedCalcId、transactions[]。
loan-calc:metaschemaVersion、是否已注入种子数据。

验收重点

  • 四 Tab 均可达，计算 → 结果 → 摊还 → 保存 → 记账复看闭环可走通；标签筛选与记一笔可用。
  • 储蓄目标可新建、存入、进度环数值正确；从结果页跳转预填生效。
  • 刷新页面后数据仍在；导出 JSON 可再导入（若实现导入则一并验收，否则仅导出）。
  • 视觉符合 Revolut 深色与渐变 CTA，金额 tabular 对齐。
  • 离线：断网后功能不受影响（无网络请求）。
