贷款计算器

手机端优先的离线贷款计算器（含专用车贷路径）+ 轻量储蓄缓冲：等额本息 / 等额本金、摊还明细、多方案对比、已保存方案与个人中心闭环；数据仅存本地。视觉以 Revolut Mobile 浅色基底为准，页面信息密度向市面 EMI 工具靠拢，避免空旷。

当前方案

  • 原型意图：作为贷款类 App 的参考原型，主线专注试算与对比，弱化记账。
  • 目标用户：有房贷、车贷或消费贷规划需求的个人用户。
  • 核心体验：底部三 Tab（计算 / 储蓄 / 我的）；类型入口（房/车/消费）→ 密集输入与实时摘要 → 结果解读与对比 → 可选保存与月供缓冲。
  • 参考产品（结构参考，非 UI 抄袭）：Loanly（计算、对比、收藏）；既有 EMI / 储蓄类工具。

事实与输入

用户确认事实（2026-10-15）

  • 去掉记账 Tab与手收支「记一笔」；主线专心做计算器。
  • 底部导航：计算 / 储蓄 / 我的。
  • 已保存试算：放在我的 → 已保存方案。
  • 车贷：车价 + 首付 → 贷款额 + 利率 + 期限，结果含车贷专用汇总。
  • 本轮加入多方案对比；法/德/美式算法、可负担评估、PDF/Excel 导出留给后续。
  • 充实空旷感：计算首页与结果页一并加强信息密度。
  • Web 原型与 Flutter 真机按同一产品规则对齐；启动页等平台呈现可以不同。
  • 界面文案国际化：支持 简体中文 / English / Español，在「我的 → 偏好设置」切换，偏好写入 localStorage。
  • 端形态：手机端优先；数据仅 localStorage；设计基底 Revolut Mobile。
  • 计算模式：等额本息、等额本金；结果含摊还明细。

当前假设

  • 默认货币 USD，并在货币列表里显示为选中；列表不放 CNY。已保存的 CNY 打开时改为 USD。无汇率换算。
  • 房贷/消费贷：本金直接输入；车贷：贷款额 = 车价 − 首付（可手动改贷款额）。首付或贷款额超过车价时提示，不算结果。年利率必须大于 0，填 0 时提示「利率必须大于0」。
  • 对比：最多 3 个方案并排（利率、月供、总利息、总成本）；至少 2 个才展示表。
  • 旧 ledger 路由与手收支：实现时隐藏入口，不在 UI 展示。
  • 种子数据：1 条房贷 + 1 条车贷示例，及可选 1 个储蓄目标。

原型范围

本次呈现

  • 三 Tab：计算、储蓄、我的；覆盖输入 / 车贷 / 结果 / 摊还 / 对比 / 储蓄 / 已保存方案 / 偏好与数据。
  • 贷款类型入口：房贷、车贷、消费贷、组合贷（通用两笔合并试算，非公积金专用）。
  • 车贷字段：车价、首付（额或%）、贷款额、年利率、期限、还款方式。
  • 计算首页密度：类型瓷砖、实时月供/利息摘要、快捷期限 chips、主 CTA。
  • 结果页密度：Hero 月供、环形图、分段解读、摊还 / 加入对比 / 保存 / 设储蓄。当前结果已在已保存方案里时，不显示「保存方案」。
  • 多方案对比页：顶部摘要写明总利息最少和月供最低的方案，带上利率、期限和金额（表头仍只显示类型和利率，单行）→ 明细表 → 柱状图（月供/总利息/总成本）；表格含还款方式、首末月供、利息占比、日均利息、类型/首付等；可添加/移除（最多 3）。未满 3 个时，底部列出尚未加入的已保存方案，点按即加入当前对比。无剩余本金折线。
  • 储蓄：目标 CRUD、存入/取出、进度环。
  • 我的：资料、已保存方案、偏好、数据管理、关于我们、隐私协议。

本次不呈现

  • 记账 Tab、手收支、标签筛选账本。
  • 法/德/美式算法、可负担评估、PDF/Excel 导出。
  • 云同步、账号、KYC、提前还款、反推利率。
  • Push 系统通知。

页面与内容方案

页面/视图页面作用主要模块与内容示例数据或素材与其他页面的关系
计算 · 首页（#page=calc） 选类型并完成房贷/消费贷输入。 标题 LoanCalcMate。类型入口；还款方式；本金、利率、期限。贷款本金、车价、首付和结果说明里的金额都按千分位显示，计算时去掉逗号。快捷期限；粘性实时摘要（参数不完整时仍占位，金额为「—」）；计算 CTA。 房贷 100 万 / 3.6% / 30 年；消费贷 5 万 / 8.5% / 3 年。 车贷切表单；→ 结果；Tab → 储蓄/我的。
计算 · 车贷 车贷专用输入。 车价、首付额/比例、贷款额（联动）、利率、期限、还款方式；摘要含首付比例。 车价 18 万、首付 30%、利率 4.5%、3 年。 → 结果（车贷汇总块）。
计算 · 结果（#page=calc-result） 汇总、解读、二次动作。 Hero 月供；总利息/总成本；环形占比（组合贷按两笔月供切开，圆心为第一笔占比，下列每笔本金/利率/月供/总利息）；车贷时展示车价/首付/贷款额；分段解读；摊还、加入对比、保存、设储蓄。 由输入计算。 → 摊还 / 对比 / 已保存 / 储蓄新建。
计算 · 摊还（#page=amortization） 按月本金/利息/余额。 月/年/自定义；按月明细按年分页，每页 12 期，可翻页或选年。年份菜单限高并使用圆角。五列居中，行距与真机一致；白卡片铺在画布上。自定义区间按输入框原数字判断。结束期小于起始期时提示「结束期不得小于起始期」；期数超出 1～总期数时提示需落在该范围内。这两种情况不列出明细、不算小计，也不把数字改写成范围内的期数。 绑定当前结果。 返回结果。
计算 · 对比（#page=compare） 并排比较 2～3 个方案。 类型、本金/贷款额、利率、期限、月供、总利息、总成本；高亮更优；添加/移除。 当前结果或已保存。 ← 结果「加入对比」；可从已保存多选。
储蓄 · 列表/详情 轻量月供缓冲目标。 进度环、环下已存 / 待存 / 已取、存入/取出、简化智能提示。已取是取出流水合计，不计入进度环。已存达到或超过目标时为 100% 与已完成，列表顶部不再把它算进进行中。取出超过当前余额时提示余额不足，不记流水。详情页底部可删除目标，确认后回到列表。 示例月供缓冲金。 ← 结果预填。
我的 · 首页 / 已保存方案 资料、复看方案、设置。 点头像昵称卡片进入编辑资料（昵称、性别）。头像不单独输入，随性别切换：保密、男、女各一张。隐私协议在页内打开远程页面，当前地址为 https://www.bluebirdfintech.com/profile/privacy-consent/provision.html，正文不写在应用里。已保存方案卡片（备注或类型、收藏星、可点的「对比中」、本金/利率/期限、月供、收藏/对比或退出对比/删除）。点「对比中」进入对比页。已在槽内时底部按钮为「退出对比」，只移出这一条并留在列表。偏好设置只含语言、小数位、货币；另有数据管理、关于我们、隐私协议。 默认昵称「借款人」。 打开 → 结果；多选 → 对比。

流程与本地数据

业务数据写入 localStorage，键前缀 loan-calc:。本轮 UI 不再读写手收支 ledger，也不提供 JSON 导入或导出。

localStorage 结构（草案）

键内容
loan-calc:profile昵称、头像、性别（male / female / private）、创建时间。
loan-calc:settings货币、小数位、主题偏好。
loan-calc:calculations方案数组：id、类型（home/auto/personal）、模式、输入（含车价/首付）、输出、摊还摘要、收藏、createdAt。
loan-calc:compare-ids当前对比槽中的 calculation id 列表（最多 3）。
loan-calc:savings-goals目标数组与流水。
loan-calc:metaschemaVersion、是否已注入种子。
loan-calc:ledger-entries（遗留）本轮不展示；清空数据时可一并 wipe。

验收重点

  • 三 Tab 可达；无记账入口。
  • 房贷/车贷/消费贷均可算出结果；车贷首付联动贷款额正确。
  • 结果页有解读与对比入口；对比页可并排 2～3 案。
  • 保存后可在「我的 → 已保存方案」复看；可设储蓄目标。
  • 刷新数据仍在；离线可用；视觉仍为 Revolut 浅色，信息不空旷。
  • Flutter 真机与本规格的产品规则一致；启动页可以按平台实现。
