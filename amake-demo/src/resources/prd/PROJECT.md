# 贷款计算器

## 产品概览

- **一句话定位：** 手机端优先的离线贷款试算与轻量储蓄目标工具，帮助个人用户快速规划房贷、车贷或消费贷并保存方案。
- **产品背景：** 作为 Ax Make 项目内的**参考原型**，用于沉淀贷款类 App 的常见闭环（计算 → 结果/摊还 → 保存 → 历史 → 个人中心），并可关联月供缓冲类储蓄目标。
- **产品目标：** 在无账号、无服务端前提下，提供可信的等额本息/等额本金计算、摊还明细、本地历史与偏好管理，界面接近生产级金融工具。

## 用户与场景

| 用户/角色 | 使用场景 | 核心任务 |
| --- | --- | --- |
| 个人借款人 | 购房/购车/消费贷前在手机上演算 | 输入本金、利率、期限，查看月供与总利息 |
| 已有方案用户 | 对比或复看历史试算 | 搜索、收藏、打开历史记录 |
| 注重隐私用户 | 不愿上传财务数据 | 离线使用、本地存储、导出备份 |
| 储蓄规划用户 | 为月供准备缓冲金 | 创建储蓄目标、记录存入/取出 |

## 产品范围

### 包含

- 等额本息、等额本金计算与按月摊还明细
- 四 Tab：计算、储蓄、历史、我的
- 记账 Tab：贷款方案（标签/收藏）+ 手收支；结果页跳转储蓄（预填目标金额）
- 轻量储蓄目标 CRUD 与进度展示
- 个人中心：昵称/头像、货币与小数位偏好、JSON 导出、分项数据清空、关于与隐私
- 纯浏览器 localStorage，无登录与网络 API

### 不包含

- 账号体系、云端同步、真实放款/KYC
- 双方案对比、提前还款、反推利率/期限（规划为二期）
- 完整预算记账、多账户流水
- 系统 Push 通知（可预留 UI，不实现）
- 汇率换算（切换货币仅影响显示格式）
